# PortihMod (Fabric 1.21.11, client-only)

Таргет худ, ESP с крутящимся маркером на цели, кейстроки (WASD, прыжок, ЛКМ/ПКМ, CPS), маленький крутящийся меч в руке,
звук победы, меню на весь экран со светлой/тёмной темой.

## Управление
- Right Shift - открыть меню (меняется в Настройки -> Управление -> Бинды клавиш -> PortihMod)
- Конфиг: `.minecraft/config/portihmod.json`

## Что нового в 1.5.0
- Крутящийся квадрат на таргете (вкладка ESP): 4 стиля (квадрат, двойной, прицел, 3D вокруг тела),
  пульс при попадании, цвет по здоровью, плавное появление/исчезновение.
- ESP: рамка или уголки, заливка, дистанция, трейсеры, золотая полоска поглощения.
- Цифры урона над целью и крестик у прицела при попадании.
- Отдельная вкладка ESP в меню, подсказки к настройкам, превью маркера, цветные метки акцента.
- Оптимизация: меньше вызовов отрисовки, без мусора в кадре, отсев игроков вне экрана,
  режим качества (Вид -> Качество эффектов: Макс. FPS / Баланс / Красиво).

## Сборка
GitHub: вкладка Actions -> build -> Artifacts -> PortihMod (внутри jar).
Локально: `gradle build` (Gradle 9.2+, Java 21), jar в `build/libs/`.
Нужен Fabric Loader 0.18.4+ и Fabric API.
